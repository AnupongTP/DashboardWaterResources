DashboardWaterResources — FINAL 29 ตำบล + Strict Autocomplete + Netlify Blob Cache

สิ่งสำคัญของเวอร์ชันนี้
- Master List ตำบล = 29 รายการ
- ช่องตำบลเป็นช่องพิมพ์ค้นหา + รายการแนะนำ
- ไม่ยอมใช้ข้อความอิสระ: ต้องเลือกรายการที่ระบบอนุญาตเท่านั้น
- ชื่อมาตรฐาน = บ้านปิน
- Cache/IndexedDB/Netlify Blob ยังทำงานเหมือนเดิม

สิ่งที่ต้องทำหลังได้รับ ZIP

1) แตก ZIP แล้ว Deploy "ทั้งโปรเจกต์" ขึ้น Netlify ผ่าน Git หรือ Netlify CLI
   - Publish directory = site
   - Functions directory = netlify/functions
   - ห้ามอัปเฉพาะ site/ ด้วย Netlify Drop

2) ตั้ง Netlify Environment Variable
   WATER_SYNC_SECRET = <secret อย่างน้อย 24 ตัวอักษร>
   ถ้าใช้ Secret เดิมจากระบบ Cache และยังเป็นความลับ ใช้ค่าเดิมได้

3) Google Apps Script ของ WaterResources
   เพิ่ม/แทนที่ไฟล์:
   google-apps-script/WaterResourcesDashboardSync.gs

   ไฟล์นี้อ่าน WaterResources อย่างเดียว ไม่เขียน/แก้/ลบเซลล์

4) ตั้ง Script Properties
   WATER_DASHBOARD_SYNC_URL = https://YOUR-SITE.netlify.app/api/waterresources/sync
   WATER_DASHBOARD_SYNC_SECRET = <secret เดียวกับ Netlify>

5) หลัง Deploy เวอร์ชันนี้ ต้อง Run 1 ครั้ง
   syncWaterResourcesToDashboard()

   จำเป็น เพราะ runtime Blob ต้องสร้าง snapshot ใหม่จาก whitelist 29 ตำบล

6) ถ้ายังไม่เคยติดตั้ง Safety Trigger ให้ Run 1 ครั้ง
   installWaterDashboardSyncSafetyTriggers()

7) เปิด index.html แล้วตรวจ
   - ช่องตำบลกดแล้วเห็น 29 รายการ
   - พิมพ์ค้นหาได้
   - ข้อความที่ไม่ได้เลือกจากรายการถูก reject
   - อปท. -> ตำบล -> หมู่ -> หมู่บ้าน ทำงานสัมพันธ์กัน

8) ทดสอบ URL
   /api/waterresources/version
   /api/waterresources
