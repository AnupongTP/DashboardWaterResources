# กติกาพื้นที่รับผิดชอบที่ใช้ใน index.html

Ruleset: `2026-08-25.2`

กติกานี้สร้างจากโจทย์ อปท./เทศบาลที่ได้รับ และใช้เพื่อกรองข้อมูลใน Dashboard เท่านั้น ไม่เขียนกลับ Google Sheet

## Master List ตำบล

Dashboard อนุญาตเฉพาะ 29 รายการนี้:

`แม่กา, แม่นาเรือ, แม่ใส, บ้านตุ่น, บ้านสาง, สันป่าม่วง, บ้านต๋อม, บ้านต๊ำ, ท่าจำปี, เทศบาลเมือง, เจริญราษฎร์, แม่ปืม, แม่สุก, ป่าแฝก, บ้านเหล่า, บ้านใหม่, แม่ใจ, ศรีถ้อย, สว่างอารมณ์, บุญเกิด, ดอกคำใต้, ดอนศรีชุม, คือเวียง, บ้านปิน, จำป่าหวาย, บ้านถ้ำ, แม่อิง, สันโค้ง, ดงเจน`

ช่องกรองตำบลเป็น strict autocomplete: ผู้ใช้พิมพ์ค้นหาได้ แต่ค่าที่นำไป filter ต้องมาจาก Master List นี้เท่านั้น

## ชื่อมาตรฐาน

ชื่อที่ใช้ใน Dashboard คือ **บ้านปิน**

ระบบมี compatibility ภายในสำหรับ legacy input ที่อาจสะกดต่าง เพื่อไม่ให้แถวเดิมหลุดจาก Sync แต่ค่าที่เก็บ/แสดงใน Dashboard จะ normalize เป็น `บ้านปิน` และไม่มีการแก้เซลล์ใน Sheet

## หลักการตัดสินเขต

1. ถ้าโจทย์ระบุว่า อปท. รับผิดชอบทั้งตำบล ระบบระบุ อปท. ได้จากตำบล
2. ถ้าโจทย์แบ่งตามหมู่ ระบบใช้ `ตำบล + หมู่`
3. `ดอกคำใต้ หมู่ 1,2` ไม่ระบุ อปท. อัตโนมัติ เพราะอยู่ในรายการของทั้ง ทม.ดอกคำใต้ และ อบต.ดอกคำใต้
4. `ดอนศรีชุม หมู่ 8,9` ไม่ระบุ อปท. อัตโนมัติ เพราะโจทย์ระบุเพียง “บางส่วน” ของหมู่
5. หมู่ที่ไม่อยู่ในรายการขอบเขตของตำบลที่แบ่งเป็นหมู่จะเป็น `⚠️ ต้องยืนยันเขต อปท.`
6. ไม่ใช้ `WaterOwner` ตัดสินเขต เพราะเจ้าของ/หน่วยงานของแหล่งน้ำไม่เท่ากับเขตการปกครอง
7. 18 ตำบลชุดเดิมใน Master List ยังแสดงและกรองได้ แต่ถ้าไม่มี rule อปท. ในโจทย์ชุดนี้ จะคงสถานะ `out-of-brief` และไม่ถูกลากเข้า bucket `⚠️ ต้องยืนยันเขต อปท.` โดยผิดความหมาย

## ถ้าต้องการความแม่นยำระดับ “บางส่วนของหมู่”

ต้องเพิ่มอย่างใดอย่างหนึ่งในอนาคต:

- Polygon ขอบเขต อปท. ที่เชื่อถือได้ แล้วทำ Point-in-Polygon จาก `lat/lng`; หรือ
- ฟิลด์ `LocalAuthority` ที่เจ้าหน้าที่ตรวจสอบและบันทึกโดยตรงต่อแหล่งน้ำ

จนกว่าจะมีข้อมูลดังกล่าว ระบบตั้งใจไม่เดาเขตพื้นที่ซ้อน
