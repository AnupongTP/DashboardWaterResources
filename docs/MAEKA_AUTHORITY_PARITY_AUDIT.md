## Code comparison and analytical caveats

- `site/maeka.html` and `site/authority.html` share their original CSS rules, map/table/three-chart markup, DSS container, modals and counter markup. Authority additions are near its lines 38–49, 427–456, 468–491 and 577. The original counter wrapper is visible at `site/maeka.html:556`; the Authority wrapper has `hidden style="display:none"` at `site/authority.html:577`.
- The original full DSS is `site/assets/maeka-app.js:updateDSSPanel()` (approximately lines 353–482). The replacement is `site/assets/authority-app.js:updateDSSPanel()` (approximately lines 433–470). The original KPI explanation is `maeka-app.js:renderKpiInsight()` (approximately 565–609); the shortened replacement is `authority-app.js:renderKpiInsight()` (approximately 570–596).
- The original visitor logic is `maeka-app.js:initVisitorCounter()` (approximately lines 857–967). The Authority app has no corresponding function. The original code sends two Abacus `/hit/` GETs on the first visit of an ISO UTC day, then `/get/` for the total and 26 country buckets. The localStorage daily key is scoped to the page origin, so localhost and Production do **not** share its deduplication state merely because they share a counter namespace. Porting it without a host guard would inflate genuine counts.
- The original depth reduction rule counts rows where `depth > 0 && depthNet < depth`; it labels that as sedimentation, an **inference**, not a measured sediment test. The original individual analysis also states definite structural cracking, evaporation “1.5–2 times”, and failed water-quality standards from broad problem tags. These assertions are original copy, not measured outputs or new Authority calculations. The original overview's “28 locations” is a **fixed literal**, not computed; the user approved omitting only that parenthetical. No engineering threshold or category is being changed.
- The original KPI type explanation asserts “six types in Tambon Mae Ka” as fixed text. That assertion cannot describe an arbitrary filtered Authority dataset. The dynamic type count and original per-type percentages/top-type analysis can be retained without claiming a fixed six types. The Authority's `volumeKnown` check prevents missing measurements being treated as measured zeros; retaining it avoids a misleading average, while the original `getSafeVolume` formula remains for known rows.
- `site/assets/authority-data-adapter.js`, `authority-routes.js`, `area-responsibility.js`, `runtime-config.js`, `water-data-loader.js` and `netlify.toml` were inspected as integration dependencies. No edit to jurisdiction rules, data source or Netlify configuration is warranted for visual/functional restoration.
