## 2. สิ่งที่ spec 16 พ.ย. ห้าม แต่เอกสารนี้อนุญาต

- เพิ่ม KPI 3 ใบในหน้า scoped ให้ครบ 8 ใบตามต้นแบบ (ใช้สูตรเดียวกับหน้าจังหวัดที่มีอยู่แล้ว)
- เพิ่มแท็บ คลังภาพ / ข้อมูลเชิงลึก / คุณภาพน้ำ / เปรียบเทียบตำบล / แหล่งน้ำชำรุด ใน scoped pages
- เพิ่มช่องค้นหา/สถานะ/ปัญหา ในแถบกรองบทสรุปหน้าจังหวัด
- นำ **logic การวิเคราะห์** จากต้นแบบมาใช้ โดยป้อนข้อมูลจริงจาก `WaterData` เท่านั้น

## 3. สิ่งที่ยังห้าม (ไม่เปลี่ยน)

- ใช้ข้อมูลฝังในไฟล์ต้นแบบ หรือเอา HTML ต้นแบบทับแอป
- เปลี่ยนสูตร KPI/DSS ที่มีอยู่, jurisdiction resolver/adapters, `WaterData` (API/version/cache/fallback/fail-closed), sync, Netlify Functions/routing
- ทำให้หน้า scoped แสดงข้อมูลนอกเขต (ต้องผ่าน adapter เดิมเท่านั้น ไม่กรองด้วยชื่อตำบลตรง ๆ)
- ทำลาย selection flow, clustering, popup/fullscreen, image fallback, counter identity/guards
- ส่ง visitor hits หรือ Production writes ระหว่างทดสอบ; commit/push/merge/deploy/ปลดล็อก Netlify
- แก้ `/maeka.html` และ `maeka-app.js` เกินการเปลี่ยนชื่อ D8
- รวม filter state ข้ามแท็บ (D2)

## 4. การแบ่งเฟส (ตรวจรับทีละเฟส)

### เฟส 1 — แถบกรองหน้าจังหวัด (แผน: `plans/2026-11-17-phase1-province-filter-bar.md`)
- โครง `.gf` ตามต้นแบบ: หัวแถบ (ไอคอน, ชื่อ, จำนวน, ปุ่ม "↺ ล้างตัวกรอง"), grid ช่องกรองมีป้ายกำกับ, แถวชิป
- ลำดับ: แถว 1 = ค้นหา (กว้าง) · อำเภอ · อบต./เทศบาล · ตำบล; แถว 2 = ประเภท · สถานะ · ปัญหา
  - ≥1100px: แถว 1 `2.2fr 1fr 1fr 1fr`, แถว 2 สามช่องเท่ากัน; 700–1099px: 2 คอลัมน์ ค้นหาเต็มแถว; <700px: 1 คอลัมน์
- ค้นหา: คำหลายคำต้องพบทุกคำ ใน `name, owner, village, moo, tambon, note` (ไม่ค้น `owner` ในฐานะเขต อปท.)
- สถานะ: `ok` = `isUsable`, `bad` = `isDamaged`, `broken` = problem มี "ชำรุด" — helpers เดิมของหน้าจังหวัด
- ปัญหา: รายการจาก `PROBLEM_TAGS` ยกเว้น "ใช้งานได้" พร้อมจำนวนจากข้อมูลจริง
- ทุกตัวกรองใหม่ทำงานแบบ AND กับตัวกรองเดิมและ cross-filter; เปลี่ยนตัวกรองใด ๆ ล้าง cross-filter ตามแบบเดิม
- ชิป: แสดงตัวกรองที่เลือก กดเพื่อล้างทีละตัว (ไม่แสดงชิปของค่าที่ล็อกตาม route)
- ไม่มี "ข้อมูลล่าสุดเมื่อ…" — ระบบไม่มีค่าเวลาให้แสดง (OPEN: ใช้ version/meta ของ WaterData ได้หรือไม่ — เสนอแยก)
- แท็บรายละเอียดข้อมูลไม่เปลี่ยน (D2)

### เฟส 2 — template ร่วม 34 หน้า (แผนเขียนหลังเฟส 1 ผ่าน)
- route `/authority/*`, `/district/*` แสดงโครงหน้าจังหวัด (แท็บบทสรุป/รายละเอียด, KPI 8 ใบคู่แผนที่, แถบกรองแบบเฟส 1) จำกัดข้อมูลด้วย adapter เดิม
- ตัวกรองอำเภอ/อปท. ในหน้า scoped: ล็อกตาม route (ซ่อนหรือ disabled — ตัดสินในแผนเฟส 2 ตามต้นแบบ); ตำบล/หมู่ตามที่หน้า scoped มีอยู่
- selection flow + counter namespaces + image fallback + zero/unavailable state ย้ายเป็นโมดูลร่วม
- ทดสอบ jurisdiction ครบ 33 route + selection/cluster/popup/fullscreen/counter guards

### เฟส 3 — แท็บข้อมูลเชิงลึก + คุณภาพน้ำ ครบ 34 หน้า
- port logic จากต้นแบบ ใช้ข้อมูลจริง; ระบุข้อจำกัดข้อมูล (missing ≠ 0, `depthnet=0` OPEN)
